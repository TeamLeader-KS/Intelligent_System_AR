# Экспериментальный кандидат общей коррозии

**Не рекомендован к установке в приложение.** Это настоящий CPU fine-tune готового YOLOv8n, а не копия исходного checkpoint. Модель телефона `ai/models/best_float16.tflite` не изменена. Новый кандидат распознаёт один класс `Corrosion` (ID 0); он несовместим с текущим порядком классов Android.

Основа — SpiderBot v1, commit `d077206d805333b689637766287a6f80ec470946`, исходный SHA-256 `23616c79be9487c96a4230c11285414b9377544320775c68843afee9b15f2cd4`. Код автора MIT, исходный датасет указан автором как CC BY 4.0, Ultralytics — AGPL-3.0; см. соседний каталог `../spiderbot`.

Обучение: PyTorch 2.6.0+cpu, Ultralytics 8.3.228, seed 102, 320×320, batch 2, AdamW, до 20 эпох, patience 5. Выполнено 9 эпох; по validation выбрана эпоха 4. Входы были read-only, контейнер работал без сети, привилегий и доступа к секретам.

Данные — Roboflow 100 corrosion-bi3q3, зеркало LibreYOLO, CC BY 4.0, revision `bd945651deedd4cd61646cd152019a1a26f91101`. Взяты отдельные исходные train/valid/test-разделы. Смешанные изображения с `Slippage`/`crack` исключены целиком, класс `corrosion` (1) перенесён в `Corrosion` (0). После фильтрации: 20 train, 5 validation, 6 test. Отложенный test использован один раз после выбора лучшей эпохи; по нему модель не выбиралась.

| Измерение | Исходный кандидат, validation | Дообученный, validation |
|---|---:|---:|
| mAP50 | 0,0599 | 0,1332 |
| mAP50–95 | 0,0204 | 0,0520 |
| Recall | 0,0714 | 0,2237 |

После выбора модели на test: **mAP50 0,00773, recall 0,0667**. Это слабое обобщение. Рост на пяти validation-изображениях не является доказательством улучшения распознавания реальных насосов.

Ограничения: общие промышленные поверхности, без проверки групп физического оборудования, без отрицательных примеров, без подтверждённой насосной выборки. Возможное пересечение с данными исходной pretrained-модели неизвестно. Нет отдельных классов ржавчины/точечной коррозии, распознавания насосов или их узлов. Числа не относятся к рабочей модели Софии.

Для пригодной новой модели нужны размеченные реальные целевые насосы, независимые группы train/val/test, исправные поверхности и проверка на телефоне. Повторные эксперименты после просмотра test потребуют нового независимого итогового набора.

Файлы: `best.pt` — отдельный кандидат (не коммитится), `report.json` — машинный отчёт и SHA, `results.csv` — фактические эпохи, `environment-freeze.txt` — точные версии CPU-окружения. Веса и использованные данные включены в локальный архив `/tmp/iv-corrosion-training-starter.zip`.
