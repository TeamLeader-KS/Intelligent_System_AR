# Ограниченный эксперимент промпта Qwen

`prompt.txt` — отдельный кандидат, рабочий `backend/app/infrastructure/local_vision.py` не меняется. Весы не обучались и не заменялись. Промпт требует локализованного визуального основания: цвет краски не доказывает коррозию; капля у уплотнения не считается аномальным маслом; уровень масла требует стекла и читаемого ориентира MIN/MAX; гипотеза кожуха требует непосредственно видимой открытой муфты.

Три примера заранее известны разработчикам: KSB, синтетическая открытая муфта и синтетическое стекло с уровнем ниже MIN. Это **разработческие пробы**, а не независимый тест качества и не основание для процентов готовности. Название `normal_ksb` не удостоверяет фактическую исправность оборудования; отсутствие находок не означает исправность. Происхождение изображений — `ai/demo/pumps/manifest.json`.

`run_in_backend.py` запускается в отдельном процессе готового backend-контейнера. Он вызывает текущий `OllamaVision.analyze` и `validate_vision_result`, заменяя только `messages[0].content` в исходящем HTTP-запросе через временную функцию в памяти процесса. Схема, thumbnail 768, JPEG90, temperature0, num_predict900, num_ctx4096 и таймаут90с сохраняются от текущего адаптера. Карточка пуста (`components=[]`), поэтому правильность привязки ID этим экспериментом не проверяется. Отдельно фиксируются SHA исходного промпта адаптера, полного экспериментального запроса и схемы. Записей в БД нет.

Запускать **последовательно**, при свободном локальном Ollama, без другого инференса; не больше трёх запросов:

```sh
docker compose exec -T backend python - < ai/training/prompt-experiment-v1/run_in_backend.py > ai/training/prompt-experiment-v1/results.jsonl
```

Повторный запуск перезапишет файл; для сравнения выбирайте другое имя отчёта и не подбирайте ответы под эти три изображения. Текст промпта встроен в runner для неизменности исходного эксперимента; редактирование `prompt.txt` не изменяет runner автоматически — новая версия требует нового каталога/контракта и SHA.

`results.jsonl` содержит полные реальные ответы Ollama, валидированный результат либо ошибку, digest модели, SHA оригинала/адаптера/промпта/схемы, серверное и полное время. Ошибки и пустые ответы не считаются распознанными дефектами. Известные ошибки исходного промпта сообщены в рабочем разборе, но отдельной парной базовой серии здесь нет; сравнение скорости/качества между промптами не доказано. Итог ограничивается наблюдениями по этим трём запросам.

## Наблюдения завершённого прогона

Ровно три реальных запроса, ошибок API/валидации не было:

| Проба | Полное время | Наблюдение |
|---|---:|---|
| KSB | 78,835 с | Код «коррозия» с описанием отсутствующего масляного стекла; противоречивый ответ и повторённые рамки. |
| Синтетическая открытая муфта | 47,856 с | Кожух не отмечен; вместо этого неподтверждённые «капля смазки» и «ослабленный болт». |
| Синтетический уровень масла | 45,869 с | Уровень ниже MIN замечен, но добавлена неподтверждённая «коррозия» с рамкой всего изображения. |

**Этот кандидат не рекомендуется переносить в production.** JSON валиден, но смысл недостаточно надёжен. Это не сравнение точности с предыдущим промптом. После первого запроса родитель заменил PNG на WEBP; два следующих запроса используют опубликованные WEBP с отдельно зафиксированными SHA. Первое изображение не повторялось; перед вторым инференсом был только неуспешный поиск уже удалённого PNG.
