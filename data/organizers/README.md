# Материалы организаторов

Источник: [публичный комплект кейса на Яндекс Диске](https://disk.yandex.ru/d/CaiCoW791_PlJA). Полный read-only инвентарь получен официальным Yandex Disk Public API. В комплекте 84 исходных файла общим размером 186 299 310 байт. Каждый оригинал проверен по размеру и SHA256 публичных метаданных.

| Раздел | Файлов |
|---|---:|
| Документация / Паспорта Насосов | 25 |
| Насосные агрегаты | 21 |
| Трубопровод | 12 |
| ЭД | 11 |
| Запорная арматура | 10 |
| Вибрация | 2 |
| Температура | 2 |
| Типы дефектов промышленного оборудования.docx | 1 |

`inventory.json` фиксирует состав диска; `source-manifest.json` — исходный путь, локальный путь, размер, SHA256, источник и время загрузки каждого файла. Подписанные временные URL скачивания не публикуются. `raw/` содержит оригинальную иерархию и исключён из Git; отсутствие этой папки после клонирования не означает отсутствие инвентаря.

## Получить оригиналы после git clone

Из корня проекта, только с Docker — Python и Go на компьютере не нужны:

```sh
docker run --rm --cap-drop ALL --security-opt no-new-privileges --read-only -v "${PWD}/data/organizers:/data" -w /data python:3.12-slim python tools/download_sources.py
```

Загрузка требует интернета только при подготовке комплекта. Скрипт получает временные ссылки официальным публичным API Яндекс Диска для точных `original_path` из `source-manifest.json`; URL не сохраняются. Каждый файл публикуется атомарно после проверки размера и SHA256. Повторный запуск проверяет готовые файлы и пропускает их без сети. Если организаторы изменили файл, скрипт остановится с ошибкой проверки, а не заменит закреплённую версию незаметно.

Проверить весь локальный комплект без сети и без изменений:

```sh
docker run --rm --network none --cap-drop ALL --read-only -v "${PWD}/data/organizers:/data:ro" -w /data python:3.12-slim python tools/download_sources.py --verify-only
```

Для одного документа добавьте, например, `--file "/Температура/БД значений (температура).xlsx"`. При установленном Python 3.10+ можно выполнять `python3 data/organizers/tools/download_sources.py` напрямую: дополнительных пакетов нет. Максимум четыре файла параллельно; `--workers 1` ограничивает загрузку одним файлом. Объём полного комплекта — около 186 МБ. В PowerShell путь `${PWD}` при необходимости замените абсолютным путём проекта; на Linux можно добавить `--user UID:GID`, чтобы файлы принадлежали вашему пользователю.

`extracted/` содержит поисковый текст PDF/DOCX и таблицы DOCX. `extraction-manifest.json` указывает исходный метод и сканы без текстового слоя. `ocr-manifest.json` дополняется после каждого распознанного скана: SHA256 исходника, страницы с нумерацией от 1, DPI, средняя уверенность слов и `needs_manual_review`. Страницы в OCR TXT разделены символом form feed (`\f`). Уверенность OCR не означает достоверность технического значения: числа, марки и нормативы требуется сверять со страницей PDF. Два изображения первых страниц сохранены в `extracted/qa/` для сверки, остальные промежуточные растры удаляются.

Вибрационная и температурная базы — отдельные источники. Нормативы, ресурс, обороты и комплектация винтового AMS, центробежных насосов, Wilo и каталожных серий не объединяются по сходству названий. «Типы дефектов» содержит шесть классов оборудования, но изображения представлены лишь для четырёх папок; отсутствие фотографий остальных классов не заменяется фиктивной разметкой.

## Повторить OCR сканов

Из корня проекта, с установленным Docker:

```sh
docker build -f data/organizers/tools/Dockerfile.ocr -t iv-organizer-ocr:local data/organizers/tools
docker run --rm --network none --cap-drop ALL --security-opt no-new-privileges --read-only --tmpfs /tmp:size=512m,mode=1777 --memory 3g --cpus 4 --pids-limit 128 -v "${PWD}/data/organizers/raw:/input:ro" -v "${PWD}/data/organizers/extracted:/output:rw" iv-organizer-ocr:local
```

Команда mount с `${PWD}` приведена для shell Linux/macOS; в PowerShell используйте абсолютный путь текущего каталога. На Linux для сохранения владельца добавьте `--user UID:GID` своего пользователя. Сборке образа нужен интернет для официальных Debian-пакетов; само OCR выполняется без сети, максимум четыре документа одновременно. Production-образы проекта не изменяются.

## Права и ограничения

Материалы предоставлены организаторами для решения кейса. Открытая лицензия на весь комплект не указана; публичный доступ не означает разрешение на стороннее распространение, обучение или изменение чужих фотографий. Сохранены источники и авторские отметки. Встречаются изображения с водяными знаками и синтетические примеры: их нельзя выдавать за независимый реальный тест модели. Исходные документы не изменялись; загрузка не является обучением модели.
