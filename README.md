# Industrial Vision — быстрый локальный запуск

Локальный сервер, веб-кабинет и Android-приложение для осмотра оборудования. Для запуска нужны **Git, Go и работающий Docker с Compose и BuildKit**. Android Studio и Android SDK устанавливать не требуется: APK собирается внутри Docker.

## Запустить в две команды

```bash
git clone -b feat/local-mobile-integration https://github.com/TeamLeader-KS/Intelligent_System_AR.git
go -C Intelligent_System_AR run deploy/local/main.go
```

Если проект уже скачан, из его корня достаточно:

```bash
go run deploy/local/main.go
```

Команда автоматически:

- определяет локальный IP компьютера;
- создаёт `.env.local` со случайными паролями;
- параллельно запускает сборку сайта/API и APK;
- поднимает PostgreSQL и применяет миграции;
- загружает демонасос `pump_demo_001` с тремя узлами;
- создаёт администратора и сотрудников;
- выводит адрес сайта, логины и пароли в терминал.

**Сайт запускается, не дожидаясь APK.** На странице отображается «APK собирается», затем появляется кнопка **«Скачать APK»**. Статус обновляется автоматически. При ошибке сборки сайт продолжает работать, подробности остаются в терминале.

Первая сборка скачивает образы, Android SDK и зависимости, поэтому требует интернета. Повторные используют Docker/Gradle-кеш. Если мобильные исходники и готовый файл APK не менялись, пересборка вообще пропускается. База и фотографии сохраняются между запусками.

## Где взять логин и пароль

После запуска терминал показывает:

```text
Сайт: http://<IP компьютера>:8001/industrial-vision/
Администратор: demo_admin
Пароль администратора: <сгенерированное значение>
Android: pump_worker / pump_engineer
Пароль сотрудников: <сгенерированное значение>
```

- **В браузере:** `demo_admin` и пароль администратора.
- **В Android:** `pump_worker` или `pump_engineer` и пароль сотрудников.
- Пароли сохранены в **`.env.local`**: `IV_DEMO_ADMIN_PASSWORD` и `IV_DEMO_PASSWORD`.
- Вводите **значение после знака `=`**, а не название переменной.
- `IV_LOCAL_ADMIN_PASSWORD` — отдельный пароль PostgreSQL, он не подходит для входа на сайт.

Повторный запуск показывает те же пароли, не создаёт дубли, не сбрасывает наработку и не меняет существующие учётные записи. Если логин уже занят другой записью или пароль не совпадает, подготовка остановится с ошибкой. `.env.local` не коммитится; не удаляйте его, если хотите сохранить доступ к существующей базе.

## Установить APK на телефон

1. Подключите телефон и компьютер к одной Wi-Fi-сети.
2. Откройте на телефоне адрес сайта из терминала, обязательно с `http://` и портом `:8001`.
3. Дождитесь кнопки «Скачать APK», скачайте и установите приложение.
4. Разрешите доступ к локальной сети, если Android его запросит.
5. Приложение само найдёт сервер. Войдите как `pump_worker`.
6. Разрешите камеру. Для примера откройте на ноутбуке ссылку «Пример насоса для камеры» на сайте и наведите телефон на экран. Используйте крупный план: общие планы могут давать пропуски.

Смена Wi-Fi/IP требует повторного запуска команды на компьютере. Оставьте терминал открытым для быстрого UDP-поиска. Есть запасной поиск сервера через HTTP в текущей Wi-Fi-подсети.

VPN, гостевая Wi-Fi-сеть и изоляция клиентов на роутере могут мешать соединению. Нужны TCP 8001 и, для быстрого обнаружения, UDP 51020. Для проверки соединения откройте `http://<IP>:8001/healthz` — ожидается `{"status":"ok"}`.

Android SDK кешируется слоями Docker, Gradle и ключ подписи — отдельными BuildKit-кешами. После удаления кеша подписи может потребоваться удалить прежнюю тестовую версию приложения перед установкой новой.

## Полезные команды

Все команды ниже выполняются из корня проекта.

```bash
# Запустить сайт и демоданные без ожидания/пересборки APK:
go run deploy/local/main.go --skip-apk

# Несколько сетевых интерфейсов — явно выбрать IP:
go run deploy/local/main.go --host 192.168.1.50

# Поднять всё, дождаться APK и выйти из команды запуска:
go run deploy/local/main.go --setup-only

# Посмотреть серверные логи:
docker compose --env-file .env.local -p iv-local -f compose.local.yaml logs -f backend

# Остановить контейнеры, сохранив данные:
docker compose --env-file .env.local -p iv-local -f compose.local.yaml stop
```

При `--skip-apk` сайт использует имеющийся APK, который может соответствовать предыдущей версии исходников. Если файла нет, кнопка скачивания не появится.

Ctrl+C останавливает поиск сервера и незавершённую сборку APK; контейнеры сайта и БД продолжают работать. Повторите команду для нового запуска. Если процесс был аварийно убит и осталась `.iv-local-lock`, сначала убедитесь, что предыдущая команда завершена, и удалите только пустую папку блокировки. Volumes БД удалять не нужно.

## Что есть в демоданных и что работает

Создаются один условный насос, три компонента (насос, электродвигатель, подшипниковый узел), параметры и наработка для проверки карточки и нормативного ресурса. Всё явно отмечено как **ДЕМО**. Параметры не получены от реальных датчиков. Фиктивные осмотры и результаты нейросети не создаются.

Работают локальный вход, доступ по цеху, карточки, поиск по инвентарному номеру, история, серверный приём результатов мобильной модели и учёт обслуживания. **Распознавание живой камерой включено:** модель из `ai/models/best_float16.tflite` встраивается в APK и работает на телефоне. Порог — строго выше 0,4; дубли рамок подавляются. «Без коррозии» не отмечается как дефект, 13-й неподтверждённый класс показывается как неизвестный. Отсутствие рамок не подтверждает исправность, уверенность не определяет тяжесть повреждения. Автоматическое сохранение этих кадров и находок в историю пока не подключено.
